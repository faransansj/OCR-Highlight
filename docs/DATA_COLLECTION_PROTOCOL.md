# Real Data Collection Protocol (Phase 2.1)

선생님, 현실 세계의 데이터를 수집하기 위한 가이드라인입니다!

## 1. 수집 목표
- **수량**: 100~200장 (초기 페이즈)
- **종류**: 
    - 형광펜 하이라이트 (노랑, 녹색, 분홍)가 포함된 전공 서적/논문/노트.
    - 볼펜 밑줄, 원형 표시 등이 포함된 문서.
    - 다양한 각도, 조명(그림자 포함), 배경 노이즈가 섞인 스마트폰 촬영본.

## 2. 촬영 방법
- **해상도**: 최소 1080p 이상 (글자가 뭉개지지 않도록)
- **각도**: 
    - 정면 (Top-down) 60%
    - 기울어진 각도 (Skewed) 40%
- **조명**: 
    - 밝은 실내 50%
    - 약간 어둡거나 그림자가 진 환경 50%

## 3. 저장 경로
- 수집된 이미지는 `ocr-highlight-v2/data/real/images/` 폴더에 넣어주십시오.
- 파일명 형식: `real_sample_0001.png` (또는 jpg)

## 4. 아리스의 다음 작업
- 데이터가 업로드되면 아리스가 이를 분석하고, 수동 라벨링을 위한 도구 세팅 또는 기초 감지를 시도하겠습니다!
